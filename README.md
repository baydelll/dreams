# Иной сон — animated longread

Готовый HTML/CSS/JS-прототип на основе переданного SVG-дизайна.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для локальной разработки можно использовать любой простой static server.

## Что внутри
- `index.html` — структура страницы.
- `style.css` — адаптивная стилизация и анимации.
- `script.js` — scroll progress, reveal-анимации, навигация, parallax и cursor glow.
- `assets/design.svg` — исходный дизайн из предоставленного файла.

Интернет нужен только для подключения шрифтов Google Fonts; без него страница всё равно работает с fallback-шрифтами.
